Integration Code

Add this code to your website to integrate the widget: 

<script src="https://your-domain.com/widget/sukalp-widget.js"></script>
<script>
  new SukalpWidget('YOUR_API_KEY', {
    apiUrl: 'https://your-domain.com/api',
    position: 'bottom-right',
    theme: 'light',
    title: 'Ask AI',
    primaryColor: '#667eea'
  });
</script>
